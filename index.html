Collabor8 Music Trends Tracker

Daily snapshot: Charts, Roster Monitoring, Industry News (last 7 days)
How this stays current: ask Claude to "run today's music trends update" each morning. It will pull fresh chart positions (including day-over-day movement), refresh every song and playlist link, re-check each Collabor8 artist's Spotify presence and recent press, and re-search India music news, dropping anything older than 7 days. This file does not fetch live data on its own, it is a static snapshot until refreshed and re-saved. For a fully automatic morning refresh with no prompt from you, set this up as a recurring Cowork scheduled task, since a chat window cannot trigger itself.
